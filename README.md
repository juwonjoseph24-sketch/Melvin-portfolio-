# Melvin Gadgets – Responsive Website

A clean, modern and fully responsive website for **Melvin Gadgets**, a technology retail business selling smartphones, laptops and accessories.

Built for the **HTML, CSS and JavaScript** practical project assignment.

---

## Features

- **4 Pages:** Home, About, Products, Contact
- **Light / Dark Mode** toggle (saves preference)
- **Social media icons** (Facebook, Instagram, X, WhatsApp, YouTube)
- **CSS Flexbox** and **CSS Grid** layouts
- **Responsive** design (mobile, tablet, desktop)
- **Contact form** with JavaScript validation
- **Time-based greeting** and mobile menu

---

## How to Run

1. Unzip the folder
2. Open `index.html` in a browser
3. Click the moon/sun icon to switch light ↔ dark mode

---

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Media Queries, CSS Variables)
- Vanilla JavaScript
- Font Awesome 6 (icons)

---

## Deployment

Upload the folder to **Netlify** (drag & drop) or **Render** (Static Site).
